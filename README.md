# 🏠 Bunker

Веб-версия игры «Бункер», созданная на Vue.js.

## 🚀 Возможности

- Генерация персонажей
- Генерация характеристик
- Генерация событий
- Современный пользовательский интерфейс
- Адаптивная верстка

## 🛠️ Стек технологий

- Vue.js
- JavaScript
- HTML5
- CSS3
- Firebase


## ⚙️ Запуск

```bash
npm install
npm run dev
```
